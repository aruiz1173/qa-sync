    EXAMPLE OUTPUT — NOT A REAL RUN

    Verify sign-in with verification code (staging) - Android tablet

    Preconditions

    • QA staging account configured in the team secret manager
    • Device: Galaxy Tab A8, Android 14, app build from staging

    Steps

    1. Tap Log in on the welcome screen.

      Expected result
      • The email field takes focus.

    2. Enter the account email and password from the preconditions and tap Continue.

      Expected result
      • The verification screen opens with an empty 6-digit field.

    3. Enter the QA verification code from the team secret manager.

      Expected result
      • The home screen loads with the account name in the top bar.
    4. Optional

      Rotate the tablet to landscape.

      Expected result
      • The home screen keeps the session and re-lays out in two columns.

    5. Open the menu and tap Log out.

      Expected result
      • The login screen is shown and reopening the app does not restore the session.
